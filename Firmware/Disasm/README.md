### Python DISASM Firmware Scripts

#### Script 1: fw_unpack_gui.py

Allow to unpack .fw and .bin files to application binary code (zip archive).
> Requires: tdh9_ufw.py

#### Script 2: fw_pack_gui.py

Allow to pack application binary code (zip archive) to .fw and .bin files.
> Requires: tdh9_ufw.py

#### Script 3: fw_string_edit_gui.py

GUI to find and replace a menu string (e.g. 'MENU') inside
the TD-H9 firmware (.fw and .bin files), and rebuild/repack the file.
> Requires: tdh9_ufw.py
